# Intake: initial requirements

**Date:** 2026-11-04

This is sample input written for the demo, not real user requests.

## Raw input

> 1. I want to add a task from the terminal by giving it a title.
> 2. A task with no title makes no sense.
> 3. I want to see my tasks in a list.
> 4. My tasks must still be there after I close the terminal.
> 5. I want to mark a task as done.
> 6. Done tasks shouldn't clutter my list.
> 7. I'd like to look at my tasks in a browser too.

## Clarifications

These sample answers show how an ambiguity gets resolved and recorded.

| Item | Question | Answer | Effect |
|---|---|---|---|
| 6 | Does "shouldn't clutter" mean deleting done tasks, or hiding them? | Hide them, because I sometimes want to look back. | REQ-007 and REQ-008 |
| 7 | Should the browser page allow edits? | No, read-only for now. | REQ-011 |

## Conflicts found

Item 6 changes how item 3 behaves. Slice 001 has no way to complete a task, so REQ-003 lists everything. Slice 002 then supersedes it with REQ-007.
